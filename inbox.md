# Finance Lab Inbox

Temporary list of financial, trading, investing, and market intelligence resources to evaluate.

This inbox is used for resources that may be valuable but have not yet been fully reviewed or classified.

## Workflow

1. Save the resource here first.
2. Check the original source and license.
3. Identify its category and use case.
4. Evaluate strengths, limitations, and relevance.
5. Move it into the correct category file if it is valuable.
6. Fork only when deeper code study, modification, or long-term preservation is needed.
