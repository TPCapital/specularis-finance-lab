# Finance Resource Evaluation Framework

A structured framework for evaluating financial, trading, investing, and market intelligence resources.

The goal is not to collect as many links as possible, but to identify resources that can improve the Specularis financial research and trading system.

## Evaluation Criteria

| Criteria | Question |
|---|---|
| Source Quality | Is the project from an original, credible, or well-maintained source? |
| License | Is the license clear and compatible with learning, reference, or integration? |
| Use Case | What problem does this resource solve? |
| Reliability | Is the data, logic, or method reliable enough for research or system design? |
| Practical Value | Can it improve trading research, dashboards, execution, or risk management? |
| Integration Potential | Can it connect with Specularis Market Intelligence or Trading Model? |
| Learning Value | Does it teach useful architecture, workflow, logic, or domain knowledge? |
| Maintenance | Is the project actively maintained or still relevant? |
| Risk | Could the resource create legal, technical, financial, or execution risk? |

## Scoring System

Use a simple 1–5 score.

| Score | Meaning |
|---|---|
| 1 | Low value / not useful |
| 2 | Interesting but weak |
| 3 | Useful reference |
| 4 | Strong resource |
| 5 | Core resource worth deep study |
